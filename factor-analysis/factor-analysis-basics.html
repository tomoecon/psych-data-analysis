因子分析の基礎

1因子モデルの因子分析で複数の質問への回答の背後にある共通の要因を調べます。生活満足度の5つの質問を分析し、尺度得点の信頼性をα係数で確かめます。
公開

2026-11-20

最終更新

2026-11-25

1 目的

「今の生活に満足している」と「今の暮らしには、満足できることが多い」の2つの質問に、同じ人が答えたとします。一方に「ややあてはまる」と答えた人は、もう一方にも高めの値で答えることが多いでしょう。2つの回答が似るのは、どちらの回答にもその人の生活への満足が表れるからだと考えられます。

直接は観測できないこのような共通の要因を因子と呼びます。回答から因子を推定する方法が因子分析です。このページでは、因子を1つだけ考える1因子モデルを使います。模擬調査データの生活満足度の5つの質問を分析し、各質問が因子をどの程度反映しているかを調べます。

続いて、5つの回答を平均した尺度得点の信頼性をα係数で調べます。分析のコードはAIに作ってもらい、自分のPositronで実行して確かめましょう。

「第8節（尺度得点の信頼性）」までを読んで実行し、「第9節（練習問題）」に取り組んでください。乱数でデータを作り、因子分析の仕組みを確かめる練習は、任意の「第10節（発展）」にあります。

2 準備

ノート先に確認する動画

Moodleで指定された解説動画を確認してください。

調べたいこととデータ

ここでは模擬調査データを使います。成人1,000人が生活や仕事についてのアンケートに答えたと想定した架空のデータで、1行が1人です。本文で使うのは、生活満足度についての5つの質問への回答です。

列名 質問文
life_satisfaction_1 今の生活に満足している。
life_satisfaction_2 今の暮らしは、自分の望む生活に近い。
life_satisfaction_3 生活を全体として見れば、うまくいっていると感じる。
life_satisfaction_4 今の暮らしには、満足できることが多い。
life_satisfaction_5 今の生活には、不満が多い。（逆転項目）

どの質問にも、1（まったくあてはまらない）から5（とてもよくあてはまる）までの5段階で答えています。5番は逆転項目（他の質問と意味の向きが逆になっている質問）です。5番に5と答えた人は生活に不満を感じています。

知りたいことは、5つの回答の背後に生活への満足という因子が1つあると考えたとき、各質問がその因子をどの程度反映しているかです。

ノート模擬データについて

実際の調査の結果ではありません。質問文は授業用に作成したもので、生活満足度を適切に測れるかどうかは検証していません。5つの回答は1つの因子から生成しています。欠損値はありません。

3 分析の仕様を言葉にする

解説動画で見た1因子モデルを5つの質問について式で書きます。\(X_j\) は \(j\) 番目の質問への回答、\(f\) は5つの質問に共通する因子、\(e_j\) は \(j\) 番目の質問だけに影響する独自因子です。

\[ X_j = a_j f + e_j \quad (j = 1, 2, \dots, 5) \]

\(a_j\) は因子負荷量で、因子が回答にどれだけ表れるかを表す係数です。独自因子には、その質問だけが測っている内容や回答のぶれが含まれます。因子と独自因子は観測できないので、回答どうしの相関から因子負荷量を推定します。

psych::fa() は、回答を質問ごとに標準化した（平均0、分散1にそろえた）値で分析します。因子 \(f\) の分散も1とし、独自因子は因子とも互いにも相関しないと仮定します。すると、回答の分散1は次のように2つに分けられます。

\[ 1 = a_j^2 + V(e_j) \]

右辺の \(a_j^2\) は、回答の分散のうち因子で説明される割合です。これを共通性と呼び、\(h_j^2\) で表します。残りの \(V(e_j) = 1 - a_j^2\) は独自因子で説明される割合で、独自性と呼びます。共通性と独自性を足すと1になります。すべての質問の共通性を合計した値を寄与度、寄与度を質問の数で割った値を寄与率と呼びます。

因子得点とは、1人ずつの因子の値を推定したものです。今回は回帰法という方法で求めます。比較のため、5つの回答を1人ずつ平均した尺度得点も計算します。

項目 今回の仕様
データ 分析する5列だけを取り出した ls_items
対象 1,000人全員
分析する項目 life_satisfaction_1〜life_satisfaction_4 と逆転処理後の life_satisfaction_5_r（1〜5の整数）
因子の数 1
推定方法 最尤法。psych::fa() で fm = "ml" を指定する
数値の出力 因子負荷量・共通性・独自性・寄与度・寄与率。分析人数
因子得点 回帰法で1人ずつ求める（psych::fa() の既定の方法）。尺度得点（5列の平均）との相関係数
図 横軸が尺度得点（1〜5）、縦軸が因子得点の散布図

因子負荷量は最尤法で推定します。ロジスティック回帰と同じく、観測したデータが最も起こりやすくなる値を推定値とする方法です。psych::fa() は何も指定しないと最小残差法という別の方法を使うので、fm = "ml" で最尤法を指定します。5段階の回答は連続的な値とみなして分析します。

6 検証チェックリスト

重要検証チェックリスト

5番の因子負荷量が約−0.648と負になっている場合は、逆転処理をしていない列を分析しています。逆転処理を2回繰り返して元に戻った場合も同じです。分析した列名と summary() の5番の列を確かめてください。

因子の列名が MR1 になっている場合は、fm = "ml" が抜けています。因子負荷量は約0.789や0.755のように小数第3位だけが違う値になります。psych::fa() の既定の最小残差法で推定した結果です。値はほぼ同じですが、本文と照合するため最尤法を指定し直してください。

AIが factanal() という関数で因子分析を行うコードを返すこともあります。factanal() もRに最初から含まれる最尤法の関数で、因子負荷量と独自性は本文と同じ値になります。この教材では psych::fa() を使うので、psych::fa() で推定するよう依頼し直してください。

7 結果の解釈

因子負荷量と因子の意味

5つの因子負荷量はすべて正で、約0.65〜0.84です。正の因子負荷量は、因子の値が高い人ほど生活に満足している方向に答えやすいことを表します。5つの質問の内容に共通するのは生活への満足なので、この因子は生活満足度を表すと解釈できます。因子負荷量を計算するのはコンピュータですが、因子が何を表すかを決めるのは分析する人です。

因子負荷量が最も大きいのは4番「今の暮らしには、満足できることが多い」の約0.843です。最も小さいのは逆転処理後の5番「今の生活には、不満が多い」の約0.648です。因子負荷量が小さい質問ほど、回答に因子以外の要因が入りやすくなります。

ノートこのデータの作り方と生成時の因子負荷量

模擬調査データの回答は、実際に人に尋ねたものではありません。1因子モデルの式に沿って乱数から作ったものです。生活満足度の5つの質問は次の手順で作りました。

  1. 1,000人それぞれについて、乱数を使って生活満足度の因子の値を作ります。この値は年齢や社会的サポート、ストレスと関連するように作っています。
  2. 質問ごとに、第3節（分析の仕様を言葉にする）の式 \(X_j = a_j f + e_j\) で回答のもとになる値を計算します。因子負荷量 \(a_j\) は下の表の値です。独自因子 \(e_j\) は平均0、標準偏差 \(\sqrt{1 - a_j^2}\) の正規分布から作ります。
  3. 計算した値を−1.2・−0.4・0.4・1.2の4つの値で区切り、小さい順に1〜5の5段階にします。
  4. 5番だけは6から引いた値を記録し、逆転項目にします。

共通性は因子負荷量の2乗です。4番なら \(0.843^2 \approx 0.711\) で、4番への回答のばらつきの約71%が因子で説明されることを表します。残りの約29%が独自性で、4番の質問だけが測っている内容や回答のぶれによる部分です。5番では因子で説明される部分は約42%にとどまり、独自性の約58%のほうが大きくなっています。

因子負荷量の0.843をそのまま「84%が因子で説明される」とは読みません。割合として読めるのは2乗した共通性のほうです。

寄与度と寄与率

寄与度は約2.79で、5つの共通性を合計した値です。寄与率は約0.558で、寄与度を質問の数5で割った値です。標準化した5つの回答の分散を合計すると5になります。そのうち約56%を1つの因子で説明できたことになります。

因子得点と尺度得点

因子得点は1,000人の平均が0になるように求められます。1人目の因子得点は約−0.102で、因子の値は平均よりわずかに低いと推定されます。2人目は約−1.718で、生活への満足が平均よりかなり低いと推定されます。

尺度得点と因子得点の相関係数は約0.993です。散布図でも点はほぼ1本の線に沿って並びます。尺度得点は5つの回答を同じ重みで平均した値です。因子得点は因子負荷量の大きい4番などを重く扱います。今回は5つの因子負荷量が近いので、2つの得点はほとんど同じ順に人を並べます。それでも、同じ尺度得点の人どうしで因子得点が少しずつ違います。重みの大きい4番に高く答えた人ほど、因子得点が高くなるためです。

この結果から言えないこと

今回は因子が1つだと決めて分析しました。5つの回答が本当に1つの因子で説明できるかは、この分析だけでは確かめていません。因子の数を決める方法は探索的因子分析のページで扱います。

また、この因子を生活満足度と解釈したのは、質問文の内容によるものです。因子分析の結果だけから、因子が生活満足度を正しく測っているとまでは言えません。このデータの質問文は授業用に作ったもので、生活満足度を適切に測れるかどうかは検証していません。

8 尺度得点の信頼性（α係数）

知りたいこと

心理学の研究では、複数の質問への回答を平均した尺度得点を分析によく使います。尺度得点を使うときは、その得点がどの程度安定して測れているかも報告します。この安定の程度を信頼性と呼びます。

信頼性の指標としてよく使われるのが、α係数（クロンバックのα）です。α係数は、尺度に含まれる質問どうしの相関が高いほど大きくなります。質問の数が多いほど大きくなる性質もあり、最大で1になります。

ノートα係数の計算式

質問の数を \(k\) とします。\(j\) 番目の質問への回答の分散を \(V(X_j)\)、回答の合計の分散を \(V(X_1 + \dots + X_k)\) とすると、α係数は次の式で求められます。

\[ \alpha = \frac{k}{k - 1}\left\{1 - \frac{V(X_1) + \dots + V(X_k)}{V(X_1 + \dots + X_k)}\right\} \]

質問どうしの相関が高いと、合計の分散は各質問の分散の和より大きくなります。そのため括弧の中の分数が小さくなり、α係数は1に近づきます。

AIへの指示と参照コード

α係数は psych の alpha() で求めます。第4節（AIへの指示例）の指示例でコードを作ってもらった会話に、続けて次のように依頼してください。

重要α係数の検証チェックリスト

raw_alpha が約0.49と小さく、Some items で始まる警告が出る場合は、逆転処理をしていない列を渡しています。この例は問3の解答でも扱います。

生活満足度の5つの質問のα係数は約0.86です。5つの回答はよくそろっており、尺度得点の信頼性は高いと言えます。

その質問を除いたときのα係数は約0.81〜0.85で、どれも5問すべてで求めた0.86より小さくなります。因子負荷量が最も小さかった5番を除いても、α係数は約0.85に下がります。どの質問も尺度得点の信頼性を高めることに役立っています。

論文では、α係数が0.7や0.8以上であることを目安にすることがよくあります。ただし、これらの値は慣習として使われている目安で、はっきりした根拠のある基準ではありません。α係数は質問の数を増やすだけでも大きくなるので、値だけで尺度の良し悪しを決めないようにしましょう。

α係数と因子分析では分かることが違います。α係数が高くても、質問への回答が1つの因子で説明できるとは限りません。2つ以上の因子が背後にある質問でも、質問どうしの相関がある程度高く質問の数が多ければ、α係数は高くなることがあります。回答の背後にいくつの因子があるかは、因子分析で調べます。

ノート因子負荷量から求める信頼性：ω係数

1因子モデルの因子負荷量からも、尺度得点の信頼性を求められます。この値をω係数と呼びます。計算式の分子は因子負荷量の合計の2乗で、分母はそれに独自性の合計を足した値です。

\[ \omega = \frac{(a_1 + \dots + a_5)^2}{(a_1 + \dots + a_5)^2 + (1 - a_1^2) + \dots + (1 - a_5^2)} \]

loadings_ls <- fa_ls$loadings[, 1]
sum(loadings_ls)^2 / (sum(loadings_ls)^2 + sum(1 - loadings_ls^2))
[1] 0.8621633

今回のω係数は約0.862で、α係数の約0.860とほぼ同じです。因子負荷量どうしが近いと、2つの値は近くなります。1因子モデルが当てはまる場合、因子負荷量が質問によって大きく違うほど、α係数はω係数より小さくなります。

5番の因子負荷量は本文の0.648と符号だけが逆で、1〜4番は本文と同じ値です。逆転処理は回答の向きを反対にするだけなので、5番と他の質問との相関係数は符号だけが変わります。そのため、因子負荷量も符号だけが変わります。共通性・寄与度・寄与率は因子負荷量を2乗して求めるので、本文と同じ値になります。

寄与率が本文と同じでも、因子負荷量の符号を見落とすと、「不満が多いと答える人ほど生活満足度が高い」と読み違えます。また、この表のまま5列の平均を求めると、尺度得点の計算を誤ります。他の質問と因子負荷量の符号が違う質問があれば、その質問が逆転項目かどうかを質問文で確かめてください。

10 発展（任意）

この節では、因子負荷量を自分で決めて乱数でデータを作り、因子分析でその値を推定できるかを確かめます。実際の調査では本当の因子負荷量は分かりませんが、自分で作ったデータなら推定値と比べられます。データは、第7節（結果の解釈）の折りたたみ「このデータの作り方と生成時の因子負荷量」で説明した作り方を簡単にして作ります。乱数の生成と set.seed() については、生成AIと統計プログラミングのページで説明しています。

この節のコードは短いので、AIに頼まずにそのまま実行してかまいません。出力の数値を決めた値と比べながら進めてください。

因子負荷量を決めてデータを作る

例えば、1,000人について観測変数を4つ作る場合を考えてみましょう。因子 \(f\) は平均0、分散1の正規分布から作ります。観測変数 \(X_1\)〜\(X_3\) の因子負荷量は0.9・0.8・0.7とします。\(X_4\) は因子と関係のない変数で、因子負荷量は0です。

独自因子 \(e_j\) の標準偏差は \(\sqrt{1 - a_j^2}\) にします。こうすると、観測変数の分散は \(a_j^2 \times 1 + (1 - a_j^2) = 1\) になります。このとき共通性は \(a_j^2\) なので、\(X_1\)〜\(X_3\) の共通性は0.81・0.64・0.49になるはずです。

set.seed(123)
n <- 1000
f <- rnorm(n)  # 因子
x1 <- 0.9 * f + rnorm(n, sd = sqrt(1 - 0.9^2))
x2 <- 0.8 * f + rnorm(n, sd = sqrt(1 - 0.8^2))
x3 <- 0.7 * f + rnorm(n, sd = sqrt(1 - 0.7^2))
x4 <- rnorm(n)  # 因子と関係のない変数
sim <- data.frame(x1, x2, x3, x4)

rnorm(n) は平均0、標準偏差1の正規分布から n 個の乱数を作ります。sd を指定すると標準偏差を変えられます。x1 の行では、因子に0.9を掛けた値に独自因子の乱数を足して \(X_1 = 0.9 f + e_1\) を作っています。作った4つの変数は sim という表にまとめます。

相関を確かめる

1因子モデルでは、2つの観測変数の相関係数は因子負荷量の積になります。例えば、\(X_1\) と \(X_2\) の相関係数は \(0.9 \times 0.8 = 0.72\) です。\(X_4\) の因子負荷量は0なので、\(X_4\) と他の変数の相関係数は0です。作ったデータで確かめます。

round(cor(sim), 2)
     x1   x2   x3   x4
x1 1.00 0.73 0.63 0.07
x2 0.73 1.00 0.58 0.02
x3 0.63 0.58 1.00 0.02
x4 0.07 0.02 0.02 1.00

\(X_1\) と \(X_2\) の相関係数は0.73で、0.72に近い値です。\(X_1\) と \(X_3\) は0.63（\(0.9 \times 0.7 = 0.63\)）、\(X_2\) と \(X_3\) は0.58（\(0.8 \times 0.7 = 0.56\)）です。\(X_4\) と他の変数の相関係数は0.02〜0.07で、ほぼ0です。因子分析はこの関係を逆にたどり、相関係数から因子負荷量を求めます。

3つの変数で因子分析する

まず x1〜x3 の3つだけで因子分析を行い、結果を sim_fa1 に保存します。

sim_fa1 <- sim |>
  dplyr::select(x1, x2, x3) |>
  psych::fa(nfactors = 1, fm = "ml")
print(sim_fa1$loadings, cutoff = 0)

Loadings:
   ML1  
x1 0.891
x2 0.821
x3 0.707

                 ML1
SS loadings    1.967
Proportion Var 0.656

因子負荷量の推定値は0.891・0.821・0.707で、決めた0.9・0.8・0.7に近い値です。寄与率は0.656でした。決めた値から計算した寄与率は \((0.81 + 0.64 + 0.49) \div 3 \approx 0.647\) なので、これにも近い値です。推定値が決めた値と一致しないのは、1,000人分の乱数から推定しているためです。

print(sim_fa1) で全体を表示すると、当てはまりの指標に NA や -Inf が表示されます。観測変数が3つの1因子モデルでは、3つの相関をちょうど再現する因子負荷量が求まるので、当てはまりを調べる余地がないためです。ここでは因子負荷量だけを見ます。

このデータでは、本当の因子の値 f が分かっています。因子得点と f の相関係数を求めてみましょう。

cor(sim_fa1$scores[, 1], f)
[1] 0.9339899

相関係数は約0.934で、1にはなりません。因子得点は観測変数から推定した値なので、本当の因子の値とは一致しないからです。生活満足度の因子得点も同じように推定した値です。

因子と関係のない変数を加える

続いて、x4 も加えた4つの変数で因子分析を行い、結果を sim_fa2 に保存します。

sim_fa2 <- psych::fa(sim, nfactors = 1, fm = "ml")
print(sim_fa2$loadings, cutoff = 0)

Loadings:
   ML1  
x1 0.892
x2 0.819
x3 0.707
x4 0.053

                 ML1
SS loadings    1.969
Proportion Var 0.492
round(sim_fa2$communality, 3)
   x1    x2    x3    x4 
0.796 0.671 0.500 0.003

x4 の因子負荷量は0.053で、ほぼ0です。共通性は0.003で、x4 のばらつきはほとんど因子で説明されません。cutoff = 0 を付けないと、この0.053は空欄で表示されます。x1〜x3 の因子負荷量は x4 を加える前とほとんど変わりません。

寄与度は1.969で、x4 を加える前の1.967とほぼ同じです。一方、寄与率は0.656から0.492に下がりました。寄与率は寄与度を変数の数で割った値なので、因子と関係のない変数が増えると下がります。寄与率の大きさは、どの変数を分析に含めたかによって変わります。

設定を変えて試す

設定を変えて、因子分析の結果がどう変わるかを試してみましょう。結果を予想してから実行してください。

  1. x1〜x3 の因子負荷量をすべて0.4にします。sd の中の値も合わせて変えてください。共通性と寄与率はどの程度になるでしょうか。
  2. 人数 n を100にします。set.seed() の番号を変えて何回か実行し、因子負荷量の推定値が決めた値からどの程度離れるかを比べてください。
