多項ロジスティック回帰

正規雇用・非正規雇用・自営業等のように、3種類以上の値をとる変数を分析する方法を学びます。多項ロジスティック回帰で、年齢によって働き方の確率がどう違うかを調べます。
公開

2026-11-01

最終更新

2026-11-06

1 目的

働いている人のうち、年齢が高い人ほど自営業等で働く人が多いのでしょうか。年齢が1歳違うと、正規雇用・非正規雇用・自営業等のそれぞれで働いている確率はどれだけ違うのでしょうか。このページではロジスティック回帰のページと同じ架空の調査データを使い、働いている人の年齢と働き方の関係を調べます。

ロジスティック回帰のページでは、働いているかどうかという2つの値しかとらない変数を分析しました。今回の被説明変数は正規雇用・非正規雇用・自営業等の3つの値をとります。3つの値には「正規雇用のほうが上」のような順序はありません。このように順序のない3種類以上の値をとる変数を被説明変数にするモデルが、多項ロジスティック回帰です。満足度の5段階のように値に順序がある場合は、順序ロジスティック回帰という別のモデルを使います。順序ロジスティック回帰はこのページでは扱いません。

多項ロジスティック回帰では、区分の1つを比べる基準に選び、ほかの区分を基準と比べます。このページでは非正規雇用を基準にします。結果は年齢ごとの各区分の予測確率と、年齢が1歳違うときの各区分の確率の違いで読みます。分析のコードはAIに作ってもらい、自分のPositronで実行して確かめましょう。

「第7節（結果の解釈）」までを読んで実行し、「第8節（練習問題）」に取り組んでください。

2 準備

ノート先に確認する動画

Moodleで指定された解説動画を確認してください。

調べたいこととデータ

ここでは模擬調査データを使います。成人1,000人が生活や仕事についてのアンケートに答えたと想定した架空のデータで、1行が1人です。本文で使うのは次の2列です。

列名 内容 単位・値
age 年齢 20〜79歳、1歳刻みの整数
employment_status 就業区分 regular（正規雇用）/ nonregular（非正規雇用）/ self_employed（自営業等）/ not_employed（非就業）

就業区分の4種類のうち、非就業の人は今回の分析から除きます。残りの正規雇用・非正規雇用・自営業等の3区分で働いている人だけを対象にして、どの区分で働いているかを分析します。

ノート模擬データについて

実際の調査の結果ではありません。回帰の読み方を練習するため、年齢や教育年数と就業区分との関連を設定して生成しています。年齢が高い人ほど自営業等で働く人が多いのも教材上の設定です。欠損値はありません。分析結果を実在する人々の年齢と働き方の関係の証拠とは扱いません。

ファイルとRの準備

RとPositronの導入、フォルダの開き方やコードの実行方法は、「RとPositronのセットアップ」で確認してください。Positronで授業用フォルダを開き、今回のコードを保存するRスクリプトを用意します。例えば、multinomial-logistic.R という名前で保存してください。

Positronで開いている授業用フォルダに、模擬調査データのCSVを保存してください。ファイル名は mock_survey.csv です。ロジスティック回帰などのページで保存したCSVがこのフォルダにあれば、そのファイルを使えます。コードブック（データの説明書）にはすべての列の説明があります。

readr はCSVの読み込み、dplyr は行の抽出と年代ごとの集計、ggplot2 は作図に使います。tidyverseを導入済みなら、この3つの追加のインストールは不要です。

多項ロジスティック回帰の推定には、新しく nnet というパッケージを使います。nnet はRに最初から含まれているので、インストールは不要です。年齢が1歳違うときの確率の違いは、ロジスティック回帰のページと同じ marginaleffects で計算します。marginaleffects をまだインストールしていない場合は、ロジスティック回帰のページの「準備」の節を見てインストールしてください。

CSVの読み込みと働いている人の抽出

まず、CSVを読み込んで survey という名前で保存します。nrow() で1,000人分あることを確認してください。

survey <- readr::read_csv("mock_survey.csv", show_col_types = FALSE)
nrow(survey)
[1] 1000

次に、働いている人だけを取り出し、workers という名前で保存します。dplyr::filter() は条件が成り立つ行だけを残す関数です。!= は「等しくない」を表す記号なので、就業区分が not_employed でない人が残ります。条件式の書き方はデータの前処理のページでも説明しています。

あわせて、employment_status を因子（factor）という型に変えます。因子とは、区分を表す変数のための型です。factor() の levels には区分を並べる順を指定します。多項ロジスティック回帰では、この順の最初の区分が基準になります。今回は非正規雇用を基準にしたいので、nonregular を最初に書きます。この順はアルファベット順と同じですが、基準をはっきりさせるために自分で指定しておきます。

workers <- survey |>
  dplyr::filter(employment_status != "not_employed") |>
  dplyr::mutate(
    employment_status = factor(employment_status,
                               levels = c("nonregular", "regular", "self_employed"))
  )

区分ごとの人数と因子の区分の順を確かめます。

働いている人は674人で、正規雇用が361人、非正規雇用が175人、自営業等が138人です。levels() の結果で nonregular が最初に表示されていれば、非正規雇用が基準になります。元の survey とCSVファイルは変わりません。

年代ごとの働き方の割合

10歳刻みの年代ごとに、人数と3つの区分の割合を求めます。employment_status == "regular" は1人ずつ正規雇用かどうかを TRUE か FALSE で表します。mean() は TRUE を1、FALSE を0として平均を計算するので、結果は正規雇用の人の割合になります。ロジスティック回帰のページで見た、0/1の変数の平均が割合になるのと同じ考え方です。

  dplyr::group_by(age_group) |>
  dplyr::summarise(
    n = dplyr::n(),

    nonregular = mean(employment_status == "nonregular"),
    self_employed = mean(employment_status == "self_employed")
  )

3 分析の仕様を言葉にする

ロジスティック回帰では、回帰式の部分 \(\beta_0 + \beta_1 \times \text{年齢}_i\) を1つ作り、ロジスティック関数で働いている確率に変換しました。多項ロジスティック回帰では、基準以外の区分ごとに回帰式の部分を作ります。今回は非正規雇用が基準なので、正規雇用と自営業等の2つの回帰式の部分を作ります。ここでは回帰式の部分を \(z\) で表します。

\[ \begin{aligned} z_{\text{正規},i} &= \beta_{0,\text{正規}} + \beta_{1,\text{正規}} \times \text{年齢}_i \\ z_{\text{自営},i} &= \beta_{0,\text{自営}} + \beta_{1,\text{自営}} \times \text{年齢}_i \end{aligned} \]

係数には区分ごとに別の値が推定されます。例えば、\(\beta_{1,\text{正規}}\) と \(\beta_{1,\text{自営}}\) はどちらも年齢の係数ですが、同じ値になるとは限りません。

3つの区分の確率は2つの回帰式の部分から次のように求めます。

\[ \begin{aligned} \Pr(\text{正規雇用}_i) &= \frac{\exp(z_{\text{正規},i})}{1 + \exp(z_{\text{正規},i}) + \exp(z_{\text{自営},i})} \\ \Pr(\text{自営業等}_i) &= \frac{\exp(z_{\text{自営},i})}{1 + \exp(z_{\text{正規},i}) + \exp(z_{\text{自営},i})} \\ \Pr(\text{非正規雇用}_i) &= \frac{1}{1 + \exp(z_{\text{正規},i}) + \exp(z_{\text{自営},i})} \end{aligned} \]

3つの式は分母が同じで、分子を足すと分母と等しくなります。そのため、どの年齢でも3つの確率の合計は必ず1になり、どの確率も0から1の間に収まります。非正規雇用の分子の1は、基準の区分の回帰式の部分を0とみなしたときの \(\exp(0) = 1\) にあたります。区分が2つだけなら、基準以外の回帰式の部分は1つになり、確率は \(\exp(z) / \{1 + \exp(z)\}\) となります。分子と分母を \(\exp(z)\) で割ると \(1 / \{1 + \exp(-z)\}\) となり、ロジスティック回帰の式と同じです。

このモデルで知りたいことは2つです。1つ目は、20・50・79歳の人が3つの区分のそれぞれで働いている確率です。2つ目は、年齢が1歳高いと、それぞれの区分で働いている確率が平均で何ポイント違うかです。2つ目の値はロジスティック回帰のページと同じ平均限界効果で求めます。多項ロジスティック回帰では、平均限界効果も区分ごとに1つずつ求まります。

項目 今回の仕様
データ 働いている人だけを取り出した workers
対象 働いている674人
被説明変数 employment_status（因子。nonregular・regular・self_employed の順の3区分）
基準の区分 nonregular（非正規雇用）。因子の最初の区分
説明変数 age（年齢、20〜79歳の整数）
モデル 多項ロジスティック回帰。nnet::multinom() で推定する
数値の出力 summary() の結果と分析人数。20・50・79歳の各区分の予測確率。marginaleffects で求めた年齢の平均限界効果
図 横軸が年齢（20〜79歳）、縦軸が予測確率（0〜1）。3区分の予測確率を1本ずつの線で描き、線の色と種類で区分を区別する。凡例の区分名は日本語にする

employment_status は3つの値をとる区分なので、ロジスティック回帰のページのように0と1の点を並べた散布図は描きません。代わりに、年齢ごとの予測確率を区分ごとの線で描きます。

6 検証チェックリスト

重要検証チェックリスト

係数の表に nonregular の行があり、regular の行がない場合は、基準の区分が正規雇用に変わっています。AIのコードが relevel() や factor() で区分の順を変えていないか確かめてください。基準を正規雇用にすると、係数は非正規雇用の行が約0.0144、自営業等の行が約0.0392になります。係数は基準と比べた値なので、基準を変えると値が変わります。一方、予測確率と平均限界効果は基準を変えても変わりません。本文と照合するため、非正規雇用を基準にするよう依頼し直してください。

AIが分析人数を nobs() で表示するコードを返すと、no 'nobs' method is available というエラーになります。指示例のとおり、fitted() の行数で表示するよう依頼してください。multinom() に trace = FALSE を付けると、計算の途中経過は表示されません。結果は同じです。

AIが予測確率を marginaleffects::predictions() で求めた場合も、数値が上と一致すれば正解です。この教材では多項ロジスティック回帰を nnet::multinom() で推定します。AIが mlogit などの別のパッケージを使った場合は、nnet::multinom() で推定するよう依頼し直してください。

7 結果の解釈

係数は基準と比べた向きを表す

推定した係数を四捨五入して書くと、2つの回帰式の部分は次のようになります。

\[ \begin{aligned} \hat{z}_{\text{正規}} &= 1.339 - 0.0144 \times \text{年齢} \\ \hat{z}_{\text{自営}} &= -1.423 + 0.0248 \times \text{年齢} \end{aligned} \]

第3節（分析の仕様を言葉にする）の確率の式で、正規雇用の確率を非正規雇用の確率で割ると、分母が消えて \(\exp(z_{\text{正規}})\) だけが残ります。両辺の対数をとると、次の式になります。

\[ \log\left\{\frac{\Pr(\text{正規雇用})}{\Pr(\text{非正規雇用})}\right\} = \beta_{0,\text{正規}} + \beta_{1,\text{正規}} \times \text{年齢} \]

左辺の比は非正規雇用と比べて正規雇用でどれだけ働きやすいかを表します。つまり regular の行の係数は、正規雇用と非正規雇用の2つの区分を比べた値です。自営業等の行も同じで、自営業等と非正規雇用を比べた値です。どちらの行も、比べる相手は基準の非正規雇用です。

正規雇用の年齢の係数は約−0.0144で負です。年齢が高い人ほど、非正規雇用と比べて正規雇用で働いている確率の比が小さいという向きを表します。自営業等の年齢の係数は約0.0248で正なので、年齢が高い人ほど、非正規雇用と比べて自営業等で働いている確率の比が大きいという向きになります。ロジスティック回帰と同じく、係数は確率の違いとしては読みません。「1歳高いと正規雇用の確率が1.4ポイント低い」とは読まないでください。

summary() には係数のp値が表示されません。係数を標準誤差で割るとz値を求められますが、このページでは平均限界効果のp値と95%信頼区間を使います。

予測確率

20・50・79歳の予測確率をまとめると次のようになります。各行の3つの確率を足すと1になります。

年齢 非正規雇用 正規雇用 自営業等
20歳 0.235 0.672 0.093
50歳 0.271 0.504 0.225
79歳 0.254 0.311 0.434

20歳で働いている人は、約67.2%が正規雇用で働いていると予測されます。79歳ではその確率が約31.1%まで下がり、自営業等の約43.4%を下回ります。図でも、正規雇用の線と自営業等の線は71歳ごろで交わります。自営業等の確率は57歳ごろで非正規雇用の確率も上回ります。非正規雇用の確率はどの年齢でも約23〜27%でほぼ横ばいです。準備で求めた年代ごとの割合と比べると、予測確率は年代ごとの細かな増減をならし、おおまかな傾向を表しています。

平均限界効果

年齢の平均限界効果は、正規雇用が約−0.0059、自営業等が約0.0053、非正規雇用が約0.0007です。年齢が1歳高いと、正規雇用で働いている確率は平均で約0.6ポイント低く、自営業等で働いている確率は平均で約0.5ポイント高いと読みます。10歳の違いなら、正規雇用で約6ポイント低く、自営業等で約5ポイント高くなります。95%信頼区間は正規雇用が約−0.0081〜−0.0038、自営業等が約0.0036〜0.0070です。どちらも0を含みません。

非正規雇用の平均限界効果は約0.0007で、95%信頼区間は約−0.0013〜0.0026と0を含みます。p値は0.514です。非正規雇用は基準なので係数の行がありませんが、平均限界効果を見ると、年齢による非正規雇用の確率の違いはほとんどないことが分かります。2つの係数はどちらも非正規雇用と比べた値でした。それでも、非正規雇用の確率そのものは年齢によってほとんど変わりません。年齢による違いの多くは、正規雇用と自営業等の間の違いです。

3つの平均限界効果を足すと、ほぼ0になります。どの年齢でも3つの確率の合計は1なので、ある区分の確率が下がった分は、ほかの区分の確率の上昇になります。

ノート係数をオッズ比で読むには

ロジスティック回帰のページでは、働いている確率と働いていない確率の比をオッズと呼びました。多項ロジスティック回帰では、ある区分の確率と基準の区分の確率の比 \(\Pr(\text{正規雇用}) / \Pr(\text{非正規雇用})\) を基準と比べたオッズとして扱います。例えば、20歳の予測確率では \(0.672 \div 0.235 \approx 2.86\) です。20歳で働いている人では、正規雇用で働いている確率が非正規雇用の約2.86倍だと予測されます。

係数を exp() で変換した値は、年齢が1歳高いときにこのオッズが何倍になるかを表します。この値をオッズ比と呼びます。

exp(coef(model_multi))
              (Intercept)       age
regular         3.8139113 0.9857154
self_employed   0.2410822 1.0250745

正規雇用の年齢のオッズ比は約0.986です。年齢が1歳高いと、非正規雇用と比べた正規雇用のオッズは約0.986倍になります。つまり約1.4%小さくなります。自営業等の年齢のオッズ比は約1.025で、年齢が1歳高いと、非正規雇用と比べた自営業等のオッズは約1.025倍になります。どちらも確率そのものの倍率ではありません。「正規雇用の確率が1.4%低い」とは読まないでください。

論文では多項ロジスティック回帰の結果をオッズ比の表で報告することがよくあります。統計ソフトによっては、同じ値を相対リスク比（relative risk ratio）と表示します。表を読むときはどの区分が基準かを必ず確かめてください。

この結果から言えないこと

今回の分析は働いている674人の中での働き方の違いを調べたものです。ロジスティック回帰のページで見たように、年齢が高いほど働いていない人は増えます。そのため、自営業等の確率が年齢とともに上がるという結果は、働いている人の中で自営業等の割合が高いことを表します。1,000人全体の中で年齢が高いほど自営業等で働く人の割合が高いとまでは言えません。

また、今回のデータは、異なる年齢の人にある時点で一度だけ尋ねた調査です。20歳の人と79歳の人の違いは、同じ人が年齢を重ねると正規雇用から自営業等に移ることを示すとは限りません。生まれた年代による働き方の違いなど、年齢以外の違いも含まれているからです。

本文の分析はここまでです。続いて、「第8節（練習問題）」に取り組んでください。

  2. 自営業等の教育年数の係数と平均限界効果を比べ、符号が食い違っている理由を説明してください。

このデータは、年齢と教育年数を説明変数とする多項ロジスティック回帰の式から生成しています。生成時の教育年数の係数は、正規雇用が0.150、自営業等が0.025です。今回推定した0.222と0.066は674人の標本から推定した値なので、生成時の設定とは一致しません。

問2

1つ目の文は多項ロジスティック回帰の係数を確率の違いとして読んでいます。係数−0.014は非正規雇用と比べた正規雇用の確率の比についての値です。確率の違いとして読めるのは平均限界効果の約−0.0059です。年齢が1歳高いと、正規雇用で働いている確率は平均で約0.6ポイント低くなります。

2つ目の文は比べる相手を取り違えています。regular の行の係数は正規雇用と基準の非正規雇用の2つを比べた値です。自営業等は self_employed の行で、やはり非正規雇用と比べています。正規雇用の人とそれ以外の人をまとめて比べたい場合は、正規雇用なら1でそれ以外なら0の列を作ってロジスティック回帰を推定します。

workers_regular <- workers |>

問3

指示と違うのは、多項ロジスティック回帰ではなく2つの値を分析するロジスティック回帰を推定していることです。glm() で family = binomial() を指定すると、被説明変数が因子の場合は最初の区分を0、それ以外の区分をすべて1として扱います。今回の最初の区分は nonregular なので、このコードは「非正規雇用以外で働いているかどうか」を年齢に回帰しています。

model_check <- glm(employment_status ~ age, data = workers, family = binomial())
coef(model_check)
 (Intercept)          age 
 1.174817607 -0.002875898

非正規雇用なら0、それ以外なら1の列を作ってロジスティック回帰を推定すると、同じ係数になります。

workers_check <- workers |>
  dplyr::mutate(not_nonregular = dplyr::if_else(employment_status != "nonregular", 1L, 0L))
coef(glm(not_nonregular ~ age, data = workers_check, family = binomial()))
 (Intercept)          age 
 1.174817607 -0.002875898

どちらも年齢の係数は約−0.0029です。summary() の出力を見ると、係数の表には (Intercept) と age が1行ずつしかありません。多項ロジスティック回帰なら、regular と self_employed の2行に係数が並びます。表の下には binomial family と表示されます。指示どおりにするには、nnet::multinom() で推定します。

employment_status が文字列のままなら、glm() は y values must be 0 <= y <= 1 というエラーで止まります。準備で因子に変えたので、このコードはエラーなく動いてしまいます。エラーが出ないことは、指示どおりの分析であることを意味しません。係数の表の行の数と比べている区分を確かめてください。
